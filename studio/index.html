Preview

Build turns the project into a real x86_64 main.elf, packs it into a MINIRUN1 .run bundle, and can wrap that in an installable .mpkg. Everything happens in your browser.

How it works

Studio compiles your C or C++ with mcc, a small C11 and C++ compiler written for this page. .c files are C and .cpp files are C++; a project can mix them, and the program starts at main in main.cpp or main.c. For the preview it emits JavaScript that runs against an emulation of the Minimal-OS kernel (the real syscall numbers and structures from the SDK's syscall.h) with mosWM drawn on the canvas. For Build it emits x86_64 machine code and links a position-independent ELF the way the SDK's link.ld does.

Writing apps

  • For buttons, sliders, text inputs and other widgets in the MOSdesk theme, include easyui.h (try the Widgets sample, and see Docs → easyui widgets).
  • Window apps include window.h: create a window, draw ARGB8888 pixels (use 0xFF alpha), present, and poll mos_window_next_event.
  • Key events carry USB HID codes: arrows 79–82, space 44, enter 40, letters 4–29. Click the preview first so it has keyboard focus.
  • Terminal programs use stdio.h; their output appears in the Terminal window and the Output tab.
  • graphics.h draws straight to the framebuffer. It works together with minimalos.h, stdio.h and the other headers.
  • C++ programs can use std::cout from <iostream> as well as every C header.
  • Files other than .c/.cpp/.h are resources: they are packed into the .run and appear under 0:/programs/NAME/ in the preview. A root icon.bmp becomes the desktop icon in mosWM.

Compiler limits

  • No goto, bit-fields, variable-length arrays, inline assembly or statement expressions; long double is double; case labels must sit directly in the switch block.
  • C++: classes, single inheritance, virtual functions, constructors and destructors, operator overloading, references, new/delete, namespaces, function and class templates, auto, range-based for, enum class. Not supported: exceptions and RTTI (the SDK builds without them), lambdas, rvalue references, multiple inheritance, member templates and class template specialization.
  • The preview is not cycle-accurate and has no network card; SYS_PKG and SYS_EXEC report errors there.

Keys

Ctrl+Enter run · Ctrl+. stop · Ctrl+S save · Ctrl+/ comment · F1 docs for the function under the cursor (or show/hide the docs). Projects are saved in this browser.

Docs

Docs splits the screen and opens the SDK reference next to the editor. Pick a page or search for a function in the list on the left, and use ☰ to hide that list when you want more room.

Panes

Drag a pane's top bar (the Docs or Preview title, or the empty part of the editor's tab bar) to move it next to another pane; a blue bar shows where it will go. Drag the bars between panes to resize them (double-click a bar to reset). – shrinks a pane to a strip (click the strip to bring it back) and ✕ hides it; the Preview and Docs buttons show them again, and Run always brings the preview back. ⛶ shows the preview full screen (Esc leaves). The layout is kept in this browser.
